# PRD Pointer

The canonical Product Requirements Document for Psi Circle lives at the repository root:

👉 [`../prd.md`](../prd.md)

## Why this file exists but stays empty of content

`docs/PRD.md` is listed as required documentation in the PRD itself (section 20,
"Required Documentation"). To avoid two copies of the same document drifting apart,
this file intentionally does **not** duplicate the PRD content. It only points to the
root file.

**Rule:** edit `../prd.md` directly when the product requirements change. Do not paste
PRD content into this file.
