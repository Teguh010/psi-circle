# Web (Next.js) — not MVP priority

This app is intentionally empty for now. Per `AGENTS.md` §2/§3, the web client
(Next.js, TypeScript) is not a priority for the MVP and will be scaffolded in a
later phase once mobile + backend are further along.

When it is scaffolded, it should follow the same contract-first rule from
`AGENTS.md` §4: build against `docs/api/openapi.yaml`, not ad-hoc assumptions.
